## 3. What cosign v3.1.3 writes (local registry, key-signed, same storage path as keyless)
$ cosign sign --yes --key k.key localhost:5000/sigt/a@sha256:bd44eb13...          (default mode)
  tags after: ["1","sha256-bd44eb13...]                 -> no .sig tag
$ cosign sign --yes --registry-referrers-mode=legacy --key k.key localhost:5000/sigt/b@sha256:2e1a7aa4...
  tags after: ["1","sha256-2e1a7aa4..."]                 -> no .sig tag (the flag governs fetching, not writing)

## 4. What cosign v2 writes (same registry, same key)
