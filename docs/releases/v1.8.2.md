# stack-k8s 1.8.2

A patch release. The stack moves to tokenfuse v1.22.0 and scopyx v1.3.0, so a read of the web reaches Scopyx under the run that asked for it, and every image this repository builds now starts from a base pinned whole.

v1.8.1 is the tag that built the console this release pins and has no notes of its own: a signature is accepted only from a tag, so the image a release pins comes from the tag before it.

## Upgrade first

1. **Re-run the launcher, or apply the manifests of this tag.** Each image moves by tag and digest:

   | Image | 1.8.0 | 1.8.2 |
   |---|---|---|
   | tokenfuse (gateway, MCP broker, `focus-export` sidecar) | v1.21.0 | v1.22.0 |
   | tokenfuse-control-plane | v1.21.0 | v1.22.0 |
   | scopyx, scopyx chromium | v1.2.0 | v1.3.0 |
   | genaryx-console | v1.7.5 | v1.8.1 |

2. **The MCP broker follows no redirect.** An upstream that answers 301, 302, 307 or 308 now fails with `upstream error: answered ...`. The two upstreams this stack names, `http://typryx:4320/mcp` and `http://scopyx:4300`, answer directly. An upstream you added to `TOKENFUSE_MCP_UPSTREAMS` needs its final URL.
3. **A call that searched on the OpenAI door labels its run.** A run that went on to ask for a shell can now be refused where it was not before. The record is the existing `taint_raised` event.
4. **A figure you compare across this release can rise.** A body that stopped short is charged the input as reported and the output at the request's cap, under the cost basis `PartialUsage`.

## What changed

- **A fetch joins its run.** The broker forwards `x-fuse-run-id` to an upstream in `TOKENFUSE_MCP_UPSTREAM_LABELS` and to no other, and Scopyx 1.3.0 records the fetch under that run. Here that upstream is `scopyx`.
- **The broker's own security fixes.** tokenfuse v1.22.0 stops the broker's client following redirects, which could have sent the secrets it wrote into a body to a host an upstream named, and holds a tool call that arrives in a closing `message` chunk.
- **Every image this repository builds from is pinned whole (G3.9).** Each `FROM`, the Dockerfile syntax image and the build tools carry a digest, each Go stage asserts `go1.27.3`, and Dependabot moves them. Invariant 80, gate `scripts/base-images-are-pinned.sh`, 21 teeth cases (#221).
- **`stack-caddy` carries Caddy 2.11.8.** Built on go1.27.3 with `caddy-dns/cloudflare` v0.2.4 and published from v1.8.1.
