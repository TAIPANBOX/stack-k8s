tag built from genaryx main with #72, so the Bus Explorer fills on a cluster
(#82, genaryx#71): the console asks for `GENARYX_STATE_DIR` first, which
1.1.1 named, and keeps its history on the state volume. `verify.sh` gains a
check that reads the console's own startup line, `bus LIVE` and never `bus
startup failed`; the checks before it were green through the whole outage.

move with the pin, as they always have.

## Proven, and what is not

The console at 1.1.1 was proven on a fresh arm64 box by stack-single 1.1.1
the same day (`bus LIVE` at startup, `console.sqlite` on the state volume,
the store holding the gateway's `breaker_tripped` after a budgeted run;
estate-gates `PROVEN.md`). **This pin moved without a cluster run**, by
decision on 2026-09-14: the mechanism is one environment variable the same
image honours identically under compose and under Kubernetes, and the 1.1.0
cluster run of the morning stands for everything else in the set. The new
`verify.sh` check has not run on a live cluster yet; the next cluster run
is where it is first seen green (or names what it found).
