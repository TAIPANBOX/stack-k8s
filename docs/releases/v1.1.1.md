# stack-k8s 1.1.1

The launcher's half of the console's empty Bus Explorer (#82, genaryx#71):
`20-console.yaml` names the console's state volume in `GENARYX_STATE_DIR`
(`/var/lib/stack/genaryx`), so a console that honours it (genaryx#72 and
later) keeps its bus history where it can write instead of under the
root-owned `TAIPAN_HOME` config mount. The pinned set is 1.1.0's, unchanged:
the console this tag builds (`genaryx-console:v1.1.1`, from genaryx main with
#72) is what the next release pins once a run proves it, the cadence every
console composition here has followed.

The 1.1.0 notes' sentence naming a reader that stops at an unreadable
directory was wrong and is corrected there; the reader was never the cause.

## Not in this release, said plainly

- The manifests still pin `genaryx-console:v1.0.0`, whose Bus Explorer is
  empty on every cluster; `GENARYX_STATE_DIR` changes nothing for it. The pin
  moves in 1.1.2.
- No run: this release changes one environment name the pinned console
  ignores.
