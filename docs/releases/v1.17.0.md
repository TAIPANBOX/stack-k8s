# stack-k8s 1.17.0

A minor release. The gateway's spend now reaches the CostCrew console on a cluster, a piped deploy runs only a release tree whose signature verified, and the console image builds only from its lockfile. No plane moves to a new image.

## Upgrade first

1. **Re-run the launcher.** The launchers now delete the finished `bus-owner` Job before their first apply, so the owner runs again and makes the two new directories beside the bus (`focus/` and `focus/gateway/`). If you apply the manifests by hand, delete the Job first, as the README's "Upgrading the bus layout" says:

   ```bash
   kubectl -n agent-stack delete job bus-owner --ignore-not-found
   kubectl apply -k manifests/
   ```

   Without that, a Job that finished less than ten minutes ago is left alone, `focus/gateway` is never made, and the new gateway and CostCrew pods wait in `bus-ready`.
2. **A piped deploy takes a signed release.** The one-liner is now `curl -fsSL https://github.com/TAIPANBOX/stack-k8s/releases/latest/download/deploy.sh | bash -s -- ...`. It refuses a release with no signed bundle, which every release before this one is. `STACK_TAG=vX.Y.Z` picks another signed release, `INSTALL_FROM_MAIN=1` takes main unsigned, and `REF` is refused. A clone runs as before.
3. **No image moves.** Every plane keeps the pin it had in 1.16.0. This tag publishes the console image `genaryx-console:v1.17.0`, built from genaryx `cb7f779` as before but with the locked web install, and the two tunnel images; the manifests keep pinning `genaryx-console:v1.14.0`.
4. **Going back to 1.16.0 needs nothing special.** Apply the 1.16.0 manifests. The two directories under the events claim can stay: nothing in 1.16.0 mounts them.

## What changed

- **The gateway's spend reaches the CostCrew console** (#258, invariant 95). The gateway pod's `focus-export` sidecar writes one FOCUS CSV into `focus/gateway` on the events claim every 15 minutes, written to a `.partial` file and renamed, so the console never reads half of one. The CostCrew console mounts `focus/` read only and starts with `-focus-dir /var/lib/stack/focus/gateway -focus-replace-generated`, so its AI pages show real agent spend instead of the generated estate it starts with. No new disk.
- **focus-export had exported nothing since 2026-08-28** (GOTCHAS 167). It called `tokenfuse-gateway`, a binary the image does not ship, and read the failure as a quiet window. It calls `tokenfuse` now, and prints the tool's own words when a window fails.
- **A piped deploy runs only a cosign-verified release tree** (#257, invariant 94). The new `release.yml` archives the tag, signs it keyless, verifies its own signature and attaches `stack-k8s.tar.gz`, its bundle, its checksum and `deploy.sh` to the tag's release. The piped `deploy.sh` verifies the bundle for exactly `https://github.com/TAIPANBOX/stack-k8s/.github/workflows/release.yml@refs/tags/<tag>` before anything from the tree runs, checks the archive's members and its `RELEASE` file, then runs the tree's own `deploy.sh`. Only a tag on main's history is signed. The workflow's build also runs on a pull request that edits it, and it publishes only on a tag (estate-gates C17). GOTCHAS 166: `git archive --add-virtual-file` ignores `--prefix`.
- **The console image builds only from its lockfile** (#256, invariant 93, GOTCHAS 165). The web stage copies `pnpm-lock.yaml` by name, pins pnpm 11.29.0 by the sha512 of its tarball, and runs `pnpm install --frozen-lockfile` with no fallback to `npm install`.
- **Every scenario is bound to a check that exists** (#256, invariant 92). `scripts/features-are-bound.sh` resolves every binding in `features/`, and two that pointed at renamed checks are fixed.
- **The typed risk signal's prose matches what it seeds** (#256, invariant 65). With `--typed-risk-signal` the launchers have seeded a hold for a call with no signal (`when_absent: hold`) since invariant 65; the launcher headers, `manifests/56` and the README said it seeded nothing, and now a gate refuses that sentence.
- **`security-tests.sh` parses under macOS `/bin/bash` 3.2** (#104, closed; fixed in 6e6b313 and held by invariant 47).

## Evidence

- CI on #256, #257 and #258: `gates`, `fast-gates`, the six teeth shards, and on #258 the release workflow's `build` with `publish` skipped.
- `evidence/costcrew-focus-kind/run.sh` on kind v0.33.0 in an Incus VM: from an empty cluster and over an earlier one, one agent call through the gateway's stub upstream reached `focus-gateway.csv` and CostCrew logged `imported the gateway's export: ... 1 row, 1 distinct agent`.
- The console's web stage was built with `docker build --target web` on the same machine: the locked stage built, a changed pnpm hash and a missing lockfile each stopped it.
