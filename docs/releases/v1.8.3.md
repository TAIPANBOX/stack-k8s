# stack-k8s 1.8.3

A patch release. The stack moves to typryx v0.6.0, whose `openai-logprobs` backend reaches OpenAI's current models.

## Upgrade first

1. **Re-run the launcher, or apply the manifests of this tag.** One image moves by tag and digest:

   | Image | 1.8.2 | 1.8.3 |
   |---|---|---|
   | typryx (`typryx`, `typryx-wardryx-proxy`) | v0.5.1 | v0.6.0 |

2. **A cluster on the stub, on Jev or on a local model needs nothing else.** The request stays what it always was.
3. **A cluster whose `--typed-model-url` points at OpenAI moves before 2027-01-14.** OpenAI retires `gpt-4.1-mini` and `gpt-4o-mini` that day and has already shut `gpt-4.1-nano` down. Name a current model, `gpt-6-luna` for one, and set three variables on both Deployments. The launchers have no flag for them, and a later `apply` puts the manifests' environment back, so set them again after it:

   ```bash
   kubectl -n agent-stack set env deploy/typryx deploy/typryx-wardryx-proxy \
     TYPRYX_OPENAI_TOP_LOGPROBS=5 TYPRYX_OPENAI_MAX_COMPLETION_TOKENS=16 \
     TYPRYX_OPENAI_REASONING_EFFORT=none
   ```

   `gpt-4.1-mini` refuses them.

## What changed

- **A current OpenAI model answers through typryx with nothing in between.** It refuses `max_tokens` by name, refuses more than five alternatives, and reports token probabilities only at `reasoning_effort: none`. typryx v0.6.0 takes all three as settings.
- **A near-certain answer is no longer thrown away.** Those models report in steps of 2^-18, so an almost certain token can come back a few steps above zero. typryx refused that as `bad_logprobs`: 13 of 60 answers on `gpt-5.6-luna`. It now counts up to 0.001 as rounding.

## Measured

- The digest was read from ghcr.io with `docker buildx imagetools inspect` after the release run ended: `sha256:9ffe725c...`, amd64 and arm64, `go1.27.3`. `cosign verify` passed against typryx's release workflow, and `gh attestation verify` for the tag.
- `typed-mode-is-honest.sh` holds the two manifests on one tag, and the teeth cases on this pin.
- The published image, run against the hosted API on the 60 calibration items: `gpt-6-luna` 60 of 60 answered, 0.717 accurate at 0.976 mean confidence; `gpt-5.6-luna` 60 of 60, 0.583 at 0.972.
