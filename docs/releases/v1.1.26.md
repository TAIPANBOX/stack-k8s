# stack-k8s 1.1.26

The console moves to `genaryx-console:v1.1.25`, and two fixes merged since 1.1.23
ship with it.

## What moves

- **Console `v1.1.19` -> `v1.1.25`** (built by tag v1.1.25 from genaryx
  `ecaeb6a`: genaryx#88, #89, #90).
  - Felyx, the console's copilot, reads budgets from a `budgets` tool (the
    Cloud's own run and unit budgets with their spend) instead of inferring
    them from alerts, which list a run only once it is near or over its limit.
  - Every draft answer is checked against that answer's own tool results; a
    budget statement no tool returned is sent back once for revision.
  - The Money panel's runs table shows every run budget the Cloud holds, not
    only the ones that alerted.
- **The typed risk proxy can read its key** (#124): the
  `typryx-wardryx-proxy` pod gets an `fsGroup`, so the Jev key Secret it mounts
  is readable and the pod no longer crash-loops.
- **The hub entry routes `GET /v1/run-spend`** (#125), the site-scoped read a
  remote site's gateway uses to seed its runs' spend after a restart. The
  tokenfuse-cloud this release pins (v1.5.0) does not serve it yet and answers
  404, and the gateway falls back as before; it takes effect with the tokenfuse
  release that adds the route.

No other pin moves.

## Measured

On forge (k3d, three nodes), 2026-10-05, Felyx on Anthropic Haiku 4.5 through
the stack's own gateway, each answer compared with the Cloud's `GET /v1/budgets`
read the same minute:

- On console v1.1.19, asked which router runs have a budget, Felyx called
  mig-flint (budget 4500 uUSD, spent 3210) unbudgeted, and its fleet overview
  gave p1-brume's 1000 uUSD cap to p1-beryl2, which has no budget.
- On console v1.1.25, the same two questions: exactly the three budgeted runs
  with their figures (p1-brume 2008 of 1000, over; mig-brume 1278 of 1278, at;
  mig-flint 3210 of 4500, under), and an overview with no budget statement the
  tools did not return.

## Not proven

`verify.sh` and `security-tests.sh` were not run against this exact set; the
console image was set by hand on a cluster already running the 1.1.23 manifests.
#124 and #125 were proven in their own PRs, not on forge. In the second overview
Felyx also listed a run id that does not exist ("p1-beryl1") among the runs with
no budget; the check reads budget statements, not every run id an answer names.
