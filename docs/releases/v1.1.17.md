# stack-k8s 1.1.17

This tag publishes a console image whose copilot, Felyx, can reach the stack's
own gateway by its Service name. Nothing in the pinned set moves: the
manifests keep `genaryx-console:v1.1.14` until this image has run on a
cluster.

## What the tag builds

- **`genaryx-console:v1.1.17`, with genaryx#83.** Felyx's residency check,
  which refuses any endpoint it cannot prove local, accepts a hostname the
  operator names in `GENARYX_COPILOT_LOCAL_HOSTNAMES`, and only when every
  address the name resolves to is loopback, private or link-local. The check
  runs again on every connection, so a name that later resolves publicly is
  refused then. While the check is in force Felyx follows no redirect and
  reads no proxy from its environment. Unset, nothing changes: any hostname
  other than `localhost` is still refused, with no DNS lookup.

## Not in this release, said plainly

- The manifests do not yet point Felyx at the gateway or set the new
  variable; that is the next release, after a run on a cluster.
- The check has been proven against an injected resolver, not yet against
  cluster DNS.
