# stack-k8s 1.7.1

A patch. Every Go image moves to a release built on Go 1.27.3, which fixes [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809) in `crypto/x509`. The console pin follows to the image 1.7.0 built, and turning Keyryx off now leaves no record-seal Job bound to the witness.

## Upgrade

1. **Re-run the launcher, or apply the manifests of this tag.** Each Go image moves one patch, by tag and digest (#206). Each new image was built on `golang:1.27.3` or `golang:1.27.3-alpine`, read from its build provenance, and carries a cosign signature in the legacy `.sig` format that policy-controller reads.

   | Image | 1.7.0 | 1.7.1 |
   |---|---|---|
   | heraldyx | v0.8.1 | v0.8.2 |
   | idryx | v1.3.0 | v1.3.1 |
   | keyryx (custody and witness) | v0.1.2 | v0.1.3 |
   | mockryx | v0.3.0 | v0.3.1 |
   | qryx | v1.1.0 | v1.1.1 |
   | scopyx | v1.1.0 | v1.1.1 |
   | scopyx (chromium) | v1.1.0-chromium | v1.1.1-chromium |
   | typryx | v0.5.0 | v0.5.1 |
   | vouchryx | v0.6.0 | v0.6.1 |
   | wardryx | v2.4.0 | v2.4.1 |

   None of these changes configuration: each is the toolchain, plus agent-stack-go v2.0.1 in some.
2. **The console is pinned at `genaryx-console:v1.7.0` by digest** (#203), the console that reads `GENARYX_EVENTS_EXTRA` and turns a Keyryx witness finding into an incident. 1.7.0 built that image but still pinned v1.6.0. The pin covers the console, the quality-drift CronJob and the probe pods in `security-tests.sh`.
3. **Turning Keyryx off releases the record seal** (#204, #205). `keyryx/down.sh` deletes a record-seal Job that still carries the witness affinity or `TRAILRYX_SIGNER=keyryx`, so none is left bound to a witness that is gone. A read of the cluster that fails now stops the run instead of skipping a step with exit 0, and the invariant 75 gate fails on a patch file whose target it cannot read.

## Measured

- CI on #206: fast-gates, gates, secretscan and the four teeth shards green.
- Each pinned digest was read from the registry before it was written, and each image's build provenance names a Go 1.27.3 base.

## Not measured

- Nothing in this release was run on a live cluster: no image was admitted by policy-controller, and no Keyryx opt-out ran against a running record seal.
- wardryx 2.4.1 with agent tokens ran live on a single-box install (stack-single 1.4.2, forge), not on Kubernetes.
