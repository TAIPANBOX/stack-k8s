# stack-k8s 1.18.0

A minor release that moves four planes to their new releases. No setting, manifest shape or launcher step changes.

## Upgrade first

1. **Re-run the launcher, or apply the manifests.** These workloads roll to new images: the gateway (with its focus-export sidecar), the MCP broker, the control plane, the record-seal CronJob, the crypto-trend CronJob and the CostCrew console. No new Secret, no new disk.
2. **The CostCrew console moves to costcrew v0.11.0.** It reads an empty export folder as nothing to import and replaces its generated estate only for an import that brings spend (costcrew#183). This cluster never wrote a header-only file, so nothing is removed here; the console simply stops refusing an import while `focus/gateway` is still empty.
3. **The console image is rebuilt on this tag** with tokenfuse v1.26.0 as its backtest engine (`images/console.Dockerfile`, invariant 79); the manifests keep pinning the console they pinned in 1.17.0.
4. **Going back to 1.17.0 needs nothing special.** Apply the 1.17.0 manifests.
