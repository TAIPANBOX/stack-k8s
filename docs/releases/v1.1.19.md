# stack-k8s 1.1.19

This tag publishes a console image whose copilot, Felyx, reads every money
value as dollars. Nothing in the pinned set moves: the manifests keep
`genaryx-console:v1.1.17` until the next release pins this one.

## What the tag builds

- **`genaryx-console:v1.1.19`, with genaryx#84.** Felyx's tools used to hand the
  model money as bare micro-dollar integers, and on 2026-09-27, with a real key,
  one answer in three read them as dollars ("a $50 budget, $63.64 spent" for
  USD 0.05 and 0.0636). Every money field now reaches the model as a decimal
  `*_usd` value, `budget_micros` included.
