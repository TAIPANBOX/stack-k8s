# stack-k8s 1.8.5

An agent whose error budget is spent now waits for a person, on every cluster, with nothing to turn on. wardryx has been able to do this since 2.5.0. Until this release no cluster ran the measurement, read the file or carried the rule.

## Upgrade first

1. **Decide who the hold covers before you apply.** It is on by default, for every agent. An agent you attack on purpose has a spent budget, and so does one that does far heavier work than the rest of the fleet. To narrow it, change the target of `slo-burn-hold` in the `wardryx-policy` ConfigMap. To measure and record and hold nobody, delete the rule.
2. **Re-run the launcher, or apply the manifests of this tag.** One image moves by tag and digest:

   | Image | 1.8.3 | 1.8.5 |
   |---|---|---|
   | genaryx-console (the console, `quality-drift`, `verdryx-slo`) | v1.8.1 | v1.8.4 |

   1.8.4 is the tag that built the image, and it changed nothing a cluster runs.

## What changed

- **`verdryx-slo` measures every agent's error budget every six hours,** over the last 28 days of traffic, and appends to `verdryx.ndjson` on `stack-events` when one is spent. It is a container of the gateway's pod, because the traces are that pod's `emptyDir`, and it runs under a uid nothing else runs as.
- **wardryx reads that file, and one rule holds the agent.** One key of `stack-wiring` names the file to the writer and to wardryx, and the starter policy carries `slo-burn-hold`.
- **A hold does not keep itself alive.** A held call is written to the trace, so the routine sets holds apart, and an agent on hold can earn its budget back while it keeps working.
- **A bad spell ends.** `verdryx` 0.3.0 measures the window it names, so a run stops counting once the window has passed it.
- **A file wardryx cannot believe holds nobody.** The signal can only add a hold, and every other control stands without it. `/readyz` says `signal_events` is `ok`, `unreadable` or `broken`.
- **The console image carries pyarrow,** and its workflow runs the import where the image is built.

The README has what spends a budget and how a hold ends: [An agent whose error budget is spent waits for a person](../../README.md#an-agent-whose-error-budget-is-spent-waits-for-a-person).
